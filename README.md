## 🌿 نبذة عن المشروع والهيكلية الرسمية

تم بناء هذه المنصة لتكون المرجع الرقمي التفاعلي الشامل لنسب عائلة **غشيم** الكريمة، حيث تعتمد المنصة على الهيكلية الرسمية الموثقة انطلاقاً من الجد الجامع المؤسس وصولاً إلى الفروع والبطون المتعاقبة، مع تمكين المشرفين من متابعة توثيق وإضافة الأبناء والأحفاد لكل سلالة بصورة مستمرة.

```text
محمد علي غشيم (الجد الجامع)
└── يوسف
    ├── أحمد (فرع أحمد)
    │   ├── محمد ─── (أحمد، محمد، حمدو)
    │   ├── محمود
    │   ├── ابراهيم
    │   ├── عمر ─── (ابراهيم، محمد حمادة)
    │   ├── يوسف ─── (ابراهيم تركو، محمد عكاش)
    │   ├── عبد اللطيف ─── (نايف، محمود، أحمد، محمد، عبدو، ابراهيم)
    │   ├── حسن ─── (ابراهيم، محمود)
    │   ├── خليل
    │   └── عبد الله ─── (أحمد، محمد، عبد القادر، عمر)
    │
    └── مصطفى (فرع مصطفى)
        ├── عبد الحميد ─── (محمد)
        └── يوسف ─── (فارس)
```

## ✨ المميزات الرئيسية

### 🌲 شجرة تفاعلية متقدمة (D3.js Canvas)
- **عرض تفاعلي سلس:** تكبير، تصغير، وسحب الشجرة على الشاشات الكبيرة والهواتف الذكية.
- **طي وتوسيع الفروع:** إمكانية طي وتوسيع أي فرع مع إظهار عداد الأبناء (`+X`).
- **تبديل اتجاه العرض:** التبديل الفوري بين العرض الرأسي (من الأعلى للأسفل) والأفقي (من اليمين لليسار).

### 🏷️ أزرار فروع ديناميكية 100%
- تتولد فلاتر الفروع العائلية وألوانها في الشريط العلوي **تلقائياً وبشكل ديناميكي** من واقع قاعدة البيانات الفعلية.
- أي فرع جديد يُضاف أو يتم تعديله يظهر زره ولونه فوراً دون أي كود مسبق ثابت (Zero Hardcoding).

### ✏️ إدارة وتعديل الفروع مع التحديث المتتالي (Cascade Branch Edit)
- إمكانية تعديل بيانات أي فرد بما فيها **الفرع العائلي** مع قائمة مقترحات تلقائية.
- خيار ذكي: **"تحديث اسم الفرع لجميع الأبناء والأحفاد (الذرية) أيضاً"**، مما يتيح تصحيح أي خطأ في اسم الفرع وتطبيقه على كامل السلالة المندرجة تحته بنقرة واحدة.

### 🗑️ الحذف التكراري للسلالة (Cascade Delete)
- عند حذف أي فرد، يتم حذف الفرد مع **كامل ذريته من أبناء وأحفاد** لضمان نظافة واستقرار الشجرة.
- نافذة تأكيد دقيقة تُظهر اسم الشخص وإجمالي عدد الأفراد الذين سيتم حذفهم معاً لتفادي الحذف بالخطأ.

### 🔍 بحث فوري وبطاقة تفصيلية
- بحث سريع بالاسم، الكنية، أو اللقب مع تركيز الكاميرا التلقائي وتأثير إضاءة ذهبي.
- بطاقة نسب تفصيلية توضح السلسلة النسبية الكاملة للجد الجامع، بطاقة الوالد، وشبكة بطاقات الأبناء.

### 📥 محرك التصدير متعدد الصيغ
- **تحميل صورة PNG عالية الدقة (2x):** صالحة للمشاركة عبر واتساب ومواقع التواصل.
- **تصدير كمتجه Vector SVG:** للطباعة على لوحات جدارية وبوسترات بدقة غير محدودة.
- **تصدير واستيراد JSON:** لعمل نسخ احتياطية كاملة من قاعدة البيانات.

## 🌐 إدارة الشجرة والحفظ الدائم على GitHub Pages

لكي تكون التعديلات وإضافات الأبناء **دائمة وتظهر لكل من يفتح رابط موقع GitHub Pages عالمياً**:

### 1. النشر المباشر من المتصفح (زر "نشر لـ GitHub")
1. قم بتسجيل الدخول بصفة **مشرف** (رمز المرور الافتراضي: `admin123`).
2. قم بإضافة الأبناء الجدد أو تعديل البيانات حسب رغبتك.
3. ستظهر نقطة حمراء على زر **نشر لـ GitHub** في الشريط العلوي تنبهك بوجود تعديلات محلية جديدة.
4. انقر على الزر وأدخل رمز GitHub Personal Access Token الخاص بك:
   - 🔗 **رابط إنشاء الرمز المباشر:** [اضغط هنا لإنشاء رمز GitHub Token جاهز بنقرة واحدة](https://github.com/settings/tokens/new?scopes=repo&description=GhashimTreeSync)
   - ستفتح لك صفحة GitHub مجهزة تلقائياً، اختر مدة الصلاحية (مثلاً `No expiration` أو `90 days`) ثم انزل لأسفل واضغط الزر الأخضر **Generate token** وانسخ الرمز فوراً.
   - يُطلب هذا الرمز لمرة واحدة فقط ويُحفظ بأمان داخل متصفحك الشخصي لمنحك صلاحية النشر المباشر دائماً دون إعادة إدخاله.
5. اضغط **"حفظ ونشر التغييرات الآن إلى GitHub Pages"** — سيتم تحديث ملف `family-data.json` تلقائياً عبر GitHub REST API، وخلال دقيقة ستنعكس الشجرة المحدثة لجميع الزوار على الإنترنت!

### 2. التحديث اليدوي عبر Git
يمكنك أيضاً النقر على **"تحميل family-data.json"** من الواجهة واستبدال الملف في مجلد المشروع، ثم دفع التعديل:
```bash
git add family-data.json index.html
git commit -m "تحديث شجرة النسب وإضافة أفراد جدد"
git push origin master
```

### 3. زر استعادة الهيكلية الأصلية
متوفر دائماً داخل نافذة النشر أو من شريط الأدوات لاستعادة الشجرة الأساسية المعتمدة (36 فرداً) بنقرة واحدة.
