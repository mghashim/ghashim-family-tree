## ✨ المميزات

### 🔐 بوابة الحماية والخصوصية (Gatekeeper)
- شاشة ترحيبية بتصميم إسلامي تراثي فاخر
- حماية بكلمة مرور مع دعم مستويين من الصلاحيات (مشاهدة / مشرف)
- خيار "تذكر تسجيل الدخول" للجلسات المتكررة
- تنبيه متحرك (Shake Effect) عند إدخال كلمة مرور خاطئة

### 🌲 شجرة تفاعلية متقدمة (D3.js Canvas)
- عرض تفاعلي بمحرك D3.js v7 مع SVG عالي الأداء
- فروع قابلة للطي والتوسيع مع عداد الذرية لكل فرع
- تبديل فوري بين الاتجاه الرأسي (↕) والأفقي (↔)
- ترميز لوني وهندسي للأجيال والفروع العائلية

### 📱 تحسين كامل للهواتف المحمولة
- **سحب وتحريك (Pan & Drag)** بإيماءات اللمس
- **تقريب بأصبعين (Pinch-to-Zoom)** — أساسي لمستخدمي واتساب
- تصميم متجاوب (Responsive) لجميع أحجام الشاشات

### 🔍 بحث لحظي ذكي
- شريط بحث فوري يطابق بالاسم أو الكنية أو اللقب
- قائمة منسدلة تلقائية مع نتائج البحث
- تحريك الكاميرا بسلاسة نحو الفرد المُختار مع تأثير إضاءة ذهبي

### 👤 بطاقة الفرد التفصيلية
- السلسلة النسبية الكاملة حتى الجد الجامع
- شارات الجيل والفرع والكنية واللقب
- بطاقة الوالد المباشر مع زر انتقال فوري
- شبكة بطاقات الأبناء والذرية
- إمكانية رفع صورة شخصية

### 🛡️ نظام الصلاحيات المزدوج
- **وضع المشاهدة:** تصفح كامل للشجرة والبحث والتصدير
- **وضع المشرف:** إضافة أفراد جدد، تعديل البيانات، حذف أفراد
- إمكانية الترقية من مشاهد إلى مشرف في أي وقت

### 📜 أرشيف الوثيقة التاريخية
- مقدمة التوثيق والإهداء بنص المؤلف الأصلي
- مستعرض تفاعلي عالي الدقة لصورة المخطط الأصلي المطبوع
- قائمة شرف بأعيان ووجهاء العائلة المساهمين في التوثيق

### 📥 محرك التصدير المتعدد
- **PNG عالية الدقة** — لمشاركة الشجرة عبر واتساب ومنصات التواصل
- **Vector SVG** — لطباعة بوسترات ولوحات جدارية بدقة لا نهائية
- **JSON Backup** — لنسخ احتياطي كامل لقاعدة البيانات

## 🚀 التثبيت والتشغيل

### الطريقة 1: فتح مباشر
```bash
# فقط افتح الملف في المتصفح
open index.html
```

### الطريقة 2: خادم محلي (اختياري)
```bash
# باستخدام Python
python -m http.server 8080

# أو باستخدام Node.js
npx serve .
```

ثم افتح المتصفح على: `http://localhost:8080`

## 🔑 مستويات الوصول والصلاحيات

يدعم التطبيق مستويين من الوصول:

| المستوى | الوصف | الصلاحيات |
|---------|-------|----------|
| 👁️ **مشاهد** | للعائلة والزوار | تصفح الشجرة، البحث، عرض التفاصيل، التصدير |
| 🛡️ **مشرف** | للإدارة والتحكم | كل ما سبق + إضافة أفراد + تعديل بيانات + حذف أفراد |

> **ملاحظة:** رموز المرور الافتراضية موجودة في كود المصدر (`index.html`) ويمكن تغييرها بتعديل كائن `PASSWORDS` في الكود:
> ```javascript
> const PASSWORDS = {
>   admin: 'admin123',    // رمز المشرف
>   viewer: '12345'       // رمز المشاهدة
> };
> ```

## 📸 لقطات الشاشة

### شاشة الدخول وبوابة الحماية
شاشة ترحيبية بتصميم إسلامي ملكي فاخر مع حقل إدخال رمز المرور العائلي.

عرض الشجرة بتقنية D3.js مع بطاقات ملونة لكل فرد، وفروع قابلة للطي، وشريط بحث ذكي.
